## B. Mismatches found (and what was done)

   separately by |signed row sum| (58 + 4). Faithfulness pillars, size curve, same-path random and
   minimality controls = top 61 of 612 jointly by CircuitKIT's absolute node scores (21 MLPs). L4 induced
   edge mask, circuit distance, AS-NC inside/outside and overlap = top 61 jointly by |signed row sum|
   (28 MLPs). b1_en seed 0: J(pillar, cell) 0.54, J(L4, cell) 0.43, J(pillar, L4) 0.77; the cell set covers
   58 % of Σ|attribution| vs 81 % (pillar) and 90 % (L4); MLP 6/28/27/4/1/31/29 (ranks 5–12 overall) are
   outside the cell set; cell heads reach rank 92. Consequence: §4.1 faithfulness describes set A, the cells
   intervene on set B, H3 correlates A's pillars with B's locality. Done: stated in report §5; not changed
   (the per-type rule is pre-registered and changing it would re-run the grid).
2. **Necessity not measured.** Pillar 2 ablates out-of-circuit nodes (sufficiency). No artifact ablates
   the circuit and keeps the rest. Report §2.1 and the brief call the pillars "sufficiency, necessity";
   corrected in report §5.
