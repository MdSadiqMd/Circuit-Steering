# Tiny Aya Global refusal adapter (first version)

A LoRA adapter for [`CohereLabs/tiny-aya-global`](https://huggingface.co/CohereLabs/tiny-aya-global).
With it the model helps with fewer harmful requests in English, Hindi, Arabic, French and Swahili.
It has the strongest effect of our two adapters, and two known defects. It comes from the
[Circuit-Steering](https://github.com/MdSadiqMd/Circuit-Steering) study (Lexsi hackathon, Track 2b).

> **Prefer the [second adapter](https://huggingface.co/MdSadiqMd/tiny-aya-global-refusal-circuit-lora-fluent).**
> This one writes less fluent text (perplexity +26 %) and, outside English, usually keeps writing
> after its refusal sentence. The second adapter fixes both.

| | Base model | With this adapter |
|---|---|---|
| Harmful requests answered, Hindi / Arabic / French / Swahili | 12.4 % | **3.8 %** |
| Harmful requests answered, English | 8.8 % | **1.9 %** |
| Harmless prompts refused (the cost) | 3.1 % | 8.8 % |
| Perplexity on English text (fluency) | 1.00× | 1.26× |

![Harmful requests answered by language, and harmless prompts refused: base model, SafeTune steering and this adapter](https://huggingface.co/MdSadiqMd/tiny-aya-global-refusal-circuit-lora/resolve/main/figures/a22_safety.png)

Every language has 159 held-out harmful requests, and two of the three harm categories were never
used in training. An LLM judge reads each reply. SafeTune steering is the baseline we compare
against: this adapter answers 5.0 points fewer harmful requests outside English (95 % CI −7.2 to
−3.0) and refuses fewer harmless prompts.

## Quick start

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM, AutoTokenizer

base = "CohereLabs/tiny-aya-global"
tok = AutoTokenizer.from_pretrained(base)
model = AutoModelForCausalLM.from_pretrained(base, dtype="bfloat16")
model = PeftModel.from_pretrained(model, "MdSadiqMd/tiny-aya-global-refusal-circuit-lora")
```

Do not merge the adapter into the model. Merging into bf16 weights rounds 31–43 % of the change to
zero.

## The two defects

Our audit found them, and the second adapter was built to fix them.

![The two defects of this adapter, fixed in the second: replies that stop at the refusal, and perplexity on unseen text, by language](https://huggingface.co/MdSadiqMd/tiny-aya-global-refusal-circuit-lora/resolve/main/figures/adapters_defects.png)

- **It keeps writing after it refuses.** Only 1–32 % of its replies to harmful requests outside
  English are just the refusal (77 % in English).
- **It is less fluent.** Perplexity rises 26 % on English text and 40 % across five languages.

Both likely come from our training setup: the refusals ended with a token that generation ignores,
and the "keep helping" examples were the base model's single most likely replies.

## Which adapter should I use?

The second. This one answers fewer harmful requests on its released run, but averaged over three
training seeds the two are close: 5.9 % harmful requests answered outside English for this recipe,
6.6 % for the second.

| | First (this one) | Second | SafeTune steering | Base model |
|---|---|---|---|---|
| Harmful requests answered, outside English | 3.8 % | 7.1 % | 8.8 % | 12.4 % |
| Harmful requests answered, English | 1.9 % | 4.4 % | 3.8 % | 8.8 % |
| Harmless prompts refused | 8.8 % | 6.1 % | 15.3 % | 3.1 % |
| Perplexity, English text | 1.26× | 1.02× | 1.04× | 1.00× |
| Perplexity, five languages | 1.40× | 1.02× | 1.04× | 1.00× |
| Replies that stop at the refusal | 1–77 % | 84–94 % | – | – |

## What else changed

![Change against the base model on five ability checks, with 95 % intervals, for both adapters](https://huggingface.co/MdSadiqMd/tiny-aya-global-refusal-circuit-lora/resolve/main/figures/adapters_side_effects.png)

- **No clear change** in nearby facts, general knowledge, maths or instruction following.
- **Reworded facts get worse**: accuracy falls 4.0 points (95 % CI −7.0 to −1.0).
- **More harmless prompts are refused**: 3.1 % → 8.8 %. The rise is concentrated in Swahili
  (3 % → 20 %), where the harmless prompts are machine-translated idioms.

## How it was made

1. **Find the components.** CircuitKIT (EAP-IG) scores every attention head and MLP on an English
   refusal task. The top 30 % are kept: 149 of the model's 576 heads and 35 of its 36 MLPs.
2. **Train only those.** LoRA rank 8, alpha 16, learning rate 2e-4, 13.5 M trained entries. The
   head-level masks are stored as zeros in the adapter, so the restriction survives loading.
3. **Two training signals.**
   - Refuse: 80 harmful prompts of one category (weapons and violence, from MultiJail and
     HarmBench) in five languages, each paired with the model's own most frequent short refusal in
     that language.
   - Keep helping: 151 XSTest safe prompts in five languages, each paired with the base model's
     own reply.
4. **Pick the checkpoint by a rule fixed before training**, on a dev split. Step 60 of 120 was
   kept.
5. **Audit**, and compare with SafeTune steering and with the same adapter trained on random
   components.

Training took 12 minutes on an Apple M4 Max.

## Limits

- **The circuit is not why it works.** The same adapter trained on random components of the same
  size performs the same, within one point. With 35 of 36 MLPs it is also not a small circuit.
- One base model and one released run, the best of three seeds. Over three seeds, harmful
  requests answered outside English average 5.9 %.
- The judge is a local 27 B model (Qwen3.8-27B) that reads replies cut at 48 tokens. 60 of its
  labels were checked by the AI assistant that ran the analysis, not yet by a person.
- The side-effect test sets are small (per language 60 facts, 40 reworded facts, 60 MMLU
  questions), so small changes can hide. The part of our audit that looks at other circuits was
  not run on this adapter.
- This is not a guarantee of safety. The audit sees only what it measures.

## Details

<details>
<summary>How the numbers were measured</summary>

Every prompted number on this card was measured with a minimal chat format: the user turn only,
no system preamble (`chat_wrap` in `aya_circuits/model.py`,
https://github.com/MdSadiqMd/tiny-aya-circuits). Perplexity is measured on raw text. The
tokenizer's default chat template adds a system preamble of about 366 tokens. On the base model
a small English check gave identical scores in both formats; the adapter was evaluated with
the minimal one only.

</details>

<details>
<summary>Check that the published adapter is the audited one</summary>

`export_check.json` in this repo records that the PEFT-loaded adapter gives the same next-token
logits as the audited one on 78 prompts (maximum difference 0.0) and the same generations on 297
dev prompts (100 % identical).

</details>

<details>
<summary>The checkpoint rule and the release rule</summary>

Checkpoint rule, fixed before training: the earliest snapshot with dev harmful refusal ≥ 0.95 and
dev harmless refusal at most 0.05 above the base. That was step 60 of 120.

Release rule, fixed before the second adapter was trained: this adapter stays the study's official
release, because on the released seed the second one answers 3.3 points more harmful requests and
the rule allowed 3.0. We still recommend the second, because of the difference in fluency (1.02×
against 1.26×).

</details>
